# Unisa-Programmazione-Basics.
(Programmazion I)
Questo repository contiene un progetto didattico sviluppato in **Linguaggio di alto livello C** che simula la gestione di un database universitario di studenti. L'obbiettivo è dimostrare le competenze nucleari richieste nei corsi di Informatica(classe L-31) dell'Università degli Studi di Salerno.
## Carratteristiche del codice
* **Allocazione Dinamica:** Gestione della memoria a runtime tramite puntatori e l'uso di 'malloc()' e free().
* **I/O Avanzato & File Handling:** Input interattivo da terminale e persistenza dei dati tramite scrittura su file di testo('fopen', 'fprintf', 'fclose').
* **Robustezza (Errore Handling):** Controllo preventivo sui puntatori nulli e sulla valitdità dei flussi di input.
